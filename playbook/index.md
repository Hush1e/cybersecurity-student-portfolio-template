# Cybersecurity Playbook

My Playbook is organized into eight cybersecurity knowledge areas. Each artifact is placed in its primary area and tagged with the crosscutting concepts it demonstrates.

## Eight Knowledge Areas

| Area | Focus |
|---|---|
| [🧩 Component Security](component-security/) | Hardware, endpoints, devices, physical security |
| [🌐 Connection Security](connection-security/) | Networking, protocols, firewalls, wireless security |
| [🔐 Data Security](data-security/) | Encryption, backups, access control, privacy |
| [👤 Human Security](human-security/) | Awareness, social engineering, authentication, MFA |
| [🏢 Organizational Security](organizational-security/) | Governance, risk management, compliance, incident response |
| [⚖️ Societal Security](societal-security/) | Cyber law, ethics, privacy, regulatory issues |
| [💻 Software Security](software-security/) | Programming, vulnerabilities, secure coding, automation |
| [🖥️ System Security](system-security/) | Operating systems, virtualization, hardening, logging |

## Seven Crosscutting Concepts

| Concept | Meaning |
|---|---|
| 🔒 Confidentiality | Protecting information from unauthorized access or disclosure |
| ✓ Integrity | Protecting accuracy, completeness, and trustworthiness |
| ⏱ Availability | Ensuring authorized users can access information when needed |
| ⚠️ Risk | Understanding what could go wrong and how to reduce it |
| 🎯 Adversarial Thinking | Considering how attackers might approach the situation |
| 🔄 Systems Thinking | Recognizing how cybersecurity issues affect interconnected systems |
| 🤖 Responsible AI | Using AI securely, ethically, and transparently |
