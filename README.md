# Cybersecurity Playbook & Professional Portfolio — Student Template

Created by **Norma DePriest** for students in the Hocking College AAS Cybersecurity & Network Systems program. Preserves the original green, gold, and blue design and the eight-area cybersecurity playbook.

[View the live student demo](https://hush1e.github.io/cybersecurity-student-portfolio-template/) · [About the creator](https://hush1e.github.io/projects.html)

## Make your own portfolio

1. Select **Use this template → Create a new repository**. Work in your own copy.
2. Name the public repository **yourusername.github.io**, replacing `yourusername` with your GitHub username.
3. Edit `_config.yml`: update `title`, `student_name`, and `contact_email`. Set **`baseurl: ""`** for a repository named `yourusername.github.io`. If using another repository name, set `baseurl` to `"/your-repository-name"`. The value in this master repository is for the instructor demo only.
4. In **Settings → Pages**, select **Deploy from a branch → main → /(root)** and save.
5. Follow [instructions.md](instructions.md) to personalize your homepage, add artifacts, credentials, and professional work. The base URL setup above supplements the original three personal-detail edits in those instructions.

The demo contains intentional student placeholders. Replace them in your copy; do not publish private student or employer information.
